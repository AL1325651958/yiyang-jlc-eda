# 嘉立创 EDA 原理图与 PCB 操作

设计外观和布线约束以 [SKILL.md](../SKILL.md) 为准。本文件说明如何把这些要求落实到当前工程。连接失败先读 [connection.md](connection.md)，接口参数查 [api-usage.md](api-usage.md)。

## 读取和修改图元

- 修改前读取当前工程、活动文档、器件/引脚、网络、图幅或板框及相关规则；保存原生工程备份和必要的 JSON 快照。新项目先读取文档树，打开目标工程和图页，再使用对应领域 API。切换工程前处理未保存内容，不能用 `openProject` 掩盖当前图页状态问题。
- PCB 坐标使用 mil，原理图坐标使用 10 mil。统一在设计层采用 mm 时，入口集中做转换；旋转角、镜像、底层朝向和封装原点单独处理，不能把屏幕左右顺序当焊盘编号。
- 调用前查准确的方法签名、返回类型、枚举及备注；`Promise` 必须 `await`。接口所需层枚举如无法直接取得，可在查明当前版本枚举后使用具名常量映射，禁止猜测数字。
- 编辑已有图元可用其文档公开的 `modify`，或 `toAsync()` → `setState_*()` → `await done()` 模式；不同图元的方法和参数不通用。操作后重新 `get` / `getAll` 或获取真实包围框确认生效。
- 局部修改只改当前相关图元。删除前确认对象所属文档、类型及关联；不为了简化脚本清空整板、重新导入全部器件，或重跑上个版本的全量布线计划。

## 选型、符号与封装

1. 明确器件型号、规格和封装；用户已委托选型时在授权内选择并解释关键取舍。缺失且影响设计的需求按主 Skill 询问。
2. 在器件库搜索真实条目，保留 `libraryUuid` 与器件 `uuid`。创建原理图器件需要库引用对象，不能把名称、商城编号或单个 UUID 字符串当成完整器件引用。
3. 逐项核对数据手册引脚、符号引脚编号、封装焊盘编号、极性、1 脚和贴装方向；相似名称不能替代核对。电源、晶振、复位、启动、调试及去耦连接按实际型号确认。
4. 网络与物料关联是工程数据，逐脚缩写和位号显隐是显示属性。修改丝印不能改网名、焊盘映射或工程器件位号。
5. 依主 Skill 确认保护需求，再决定是否加入 USBLC6-2SC6、TVS、保险丝等保护器件。记录用户选择及拟保护的风险，不默认堆叠保护器件，也不直接移除已有保护；具体器件是否适用仍须核对数据手册和实际电路。

## 原理图

- 使用 `SCH_*` 和 `ISCH_*` 文档中公开的器件、导线、属性、矩形、Net 标签与专用电源符号接口；先读取实际引脚坐标，再接线。Net 标签附着于目标网络，不能只放一个外观相同的普通文本。
- 模块内用短导线形成可读电路，模块间按需使用网络标签；布局、A4 图框及右下角标题栏按主 Skill 执行。模块框是图形，不是电气导线，框线不能加入网络。
- 修改电源、GND 等专用符号时直接调整原对象及关联文字，旋转后核对连接端、短引线和实际图形方向；仅连接端接线，检查 GND 横杠、电源箭头等本体未被同网或其他导线穿过、重叠或共线叠画。读回坐标与旋转状态后，按正常比例及局部放大视图复核，不能仅凭锚点连接正确判定合格；修改文字要查看完整文字包围区域。
- 原理图标注复核须逐个检查电源符号与关联文字：两者完整处于所属模块框内，文字紧邻符号，无明显分离。重点检查主控附近去耦电容的 3V3 标签；若完整字形越框或 +3V3 文字远离标识，即使网络连接正确也须调整后再导出。
- T 字形电源符号按连接端及实际图形选择 0°、90°、180° 或 270° 朝向；短引线在连接端终止，接入方向与 T 字横杠垂直。旋转后读回连接端坐标与角度，并放大检查：横杠不得与导线共线重合，导线不得穿过或覆盖符号本体；仅网络连通或角度数值正确不能代替此项检查。
- 检查引脚端点、实际导线连接、交叉点和网络归属；单靠“画面上碰到一起”不能确认电气连接。保存图页，运行原理图原生检查并查看实际网络结果，再导出/读取网络映射供 PCB 比对。

## 原理图导入 PCB

- 确认目标 PCB 与原理图属于预期板对象，原理图已经保存、封装已分配且映射正确。在目标 PCB 激活后调用 `pcb_Document.importChanges`，或使用界面“从原理图导入变更”；其可选参数为原理图 UUID，不传时使用同一 Board 关联原理图；独立 PCB 须明确提供原理图 UUID，不能传 PCB 或图页 UUID。
- 导入后读回实际器件、焊盘和网表，与原理图按“器件位号 + 焊盘编号 → 网络”逐项比对。导入返回成功不能代替比对；未导入器件、悬空焊盘和错误封装必须先处理。
- 新板按“导入 → 布局 → 板框”执行。已有板框、固定连接器或结构尺寸是约束，记录并保留，不因流程顺序重新生成板框。

## 布局、手工布线和丝印

- 布局前读取真实封装本体、焊接区、轮廓和器件旋转，按功能模块确定行列及间隔。移动后核对相关走线，不能留下未修复旧线或仅按中心点判断碰撞。
- 手工决定每条网的层、线宽、明确拐点与过孔；脚本执行这些路径并检查几何，禁止自动布线、自动寻路、自动推线生成未经人工决定的路径。线宽、间距、孔径和环宽遵循当前设计规则。
- 对修改后的实际铜线执行完整同网同层拓扑检查：线端、线段交点、分支以及焊盘/过孔附近都要纳入。正常 45° 转向的两条向外射线夹角为 135°；小于 90° 的尖夹角需消除。对坐标量化设置并记录合理容差，不能用宽松容差掩盖可见锐角。
- 区分普通二段转弯与必要的 T 形分支。检查同网重复线、小回环、短阶梯和残段；优先微调拐点并合并线段。焊盘或过孔遮住交点不表示可以跳过外露铜线检查，不通过无用过孔隐藏问题。
- 逐脚丝印以真实焊盘网络生成；缩写及对应表按主 Skill。隐藏位号只改其显示属性。丝印检查包含实际字形包围框和轮廓线宽，分别检查器件/丝印视图及完整布线视图。
- 按键已有 RST、BOOT 等功能丝印时，核对对应真实位号后隐藏其 PCB 位号属性，例如 RST 对应 SW1 时只显示 RST。读回位号显示状态，并在最终预览和导出工程中确认重复位号未恢复；不得删除器件或改动真实位号。
- 0603 等小封装若自带轮廓紧贴本器件焊盘开窗，移动位号不能解决轮廓间距。可在工程内编辑封装，修剪轮廓；空间不足且位号足以辨认器件时，可将这些轮廓移至装配层，保留焊盘、器件外形和位号。共用封装须核对所有实例。界面“编辑封装 → 应用整个工程”限定于当前工程；不要用返回的系统库 UUID 去修改公共库。先保存备份，再修改并检查导出工程中的封装实际图层、所有焊盘几何及网络均正确。

## 铺铜与检查

1. 通过当前版本公开的铺铜操作或界面命令实际重建铜皮。创建/修改铺铜边界、保存文档或调用 DRC 不等于已经重新铺铜。
2. 必须用界面时，先观察并聚焦 PCB 画布，取消临时编辑状态，再执行当前版本的“重建铺铜”。快捷键以本机菜单或设置为准；此工作流曾使用 `Shift+B`，不能假定所有版本相同。观察完成状态后再检查实际填充对象和 DRC；修改后的旧铜皮可能暂时产生间距错误，应先重建再判断。
3. 原生完整 DRC 使用详细错误返回时，`await eda.pcb_Drc.check(true, false, true)` 返回错误数组；数组长度为 0 才是该次检查无错误。`includeVerboseError=false` 的重载返回布尔值，不能把数组和布尔混淆。
4. 同时检查原生未连接、原理图到 PCB 网络一致性、器件/丝印/板边碰撞、过孔完整铜环和焊盘关系、实际走线锐角及多余拐点。不放宽规则、不关检查、不通过改网名消除错误。
5. 修改任何可能影响铜皮或连通性的项目后，重新铺铜并复核对应检查。DRC 面板可能显示上一次结果，必须重新触发检查并读取本次返回；不能只引用旧面板截图。

## 保存与导出

- 先检查并保存当前版本，确认 `save()` 成功，再导出原生可编辑 `.epro`；原生项目文件包含相关工程文档与库，不能用截图代替。
- `sys_FileManager.getProjectFile` 等导出接口可能返回 `File`，HTTP 桥接的 JSON 无法直接承载文件。先 `await file.arrayBuffer()`，分块转换为 Base64 字符串，随文件名、大小返回，再由本地工具解码保存。大文件不要用一次超大展开参数转换，超过桥接超时则拆分读取/输出或使用公开的原生文件保存功能。
- 图片可以使用当前渲染区域导出；先选目标图层、适配板框、取消选择高亮，避免把调试选中态当交付预览。记录顶层、底层和丝印视图所用图层。
- 检查导出文件非空、ZIP 完整性和实际原生工程内容，并核对目标板、器件、网络及逐脚标签。确认修改后的版本已被导出，不能将修改前备份改名充当新版。
- 交付可编辑工程、必要预览及当前检查结果，说明必要 T 分支、紧凑丝印间距等实际例外；未执行的样机测试、板厂 DFM 等按事实说明，不把零 DRC 扩大解释为已完成所有制造及电气验证。
